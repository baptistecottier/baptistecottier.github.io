# baptistecottier.github.io

Source of my personal homepage: **https://baptistecottier.github.io**

Built with Jekyll and the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme.
GitHub Pages rebuilds the site on every push to `main`.

## Structure

- `index.md` — about
- `_pages/` — CV, publications, teaching & talks, puzzles
- `_config.yml` — name, sidebar links, theme
- `_data/navigation.yml` — top menu

## Preview locally

    bundle install
    bundle exec jekyll serve   # http://localhost:4000
