# baptistecottier.github.io

Personal homepage, built with Jekyll and the
[Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme
(loaded as a `remote_theme`; GitHub Pages builds it natively).

## Run locally

    bundle install
    bundle exec jekyll serve

Then open http://localhost:4000.

## Deploy

Push to a GitHub repository named `baptistecottier.github.io`, then
Settings → Pages → "Deploy from a branch" → `main` / root.
